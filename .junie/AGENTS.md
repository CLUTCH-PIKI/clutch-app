# Project Guidelines: Clutch

Clutch est une plateforme d'opinion granulaire et d'assistance promotionnelle conçue pour apporter de la clarté aux consommateurs face à la saturation publicitaire.

## Contexte du Projet
- **Vision** : L'antidote à la saturation publicitaire par la clarté et la sincérité.
- **Produit** : Centralisation d'avis consommateurs vérifiés, sincères et détaillés (opinion granulaire).
- **Fonctionnalités Clés** :
    - **Loops** : Loteries exclusives co-animées avec des influenceurs pour récompenser la communauté.
    - **Insights Marques** : Accès par abonnement aux analyses de notation des produits.
    - **Clutch UGC Program** : Bibliothèque de contenus organiques (User Generated Content) pour les marques.
- **Cibles** : Consommateurs (choix conscients), Influenceurs (engagement communauté), Marques (R&D et promotion).

## Instructions pour Junie
- Respecter le ton et la vision de Clutch dans toute documentation ou code produit.
- Garder à l'esprit les trois piliers d'utilisateurs : Consommateurs, Influenceurs, et Marques.
- **Tests et Qualité** : 
    - Tout code généré doit être accompagné de tests unitaires (Vitest).
    - Les tests doivent être valides et passer (`npm test`).
    - Le code doit être conforme aux règles de lint (`npm run lint`).
    - La sincérité et la fiabilité des avis centralisés doivent être garanties par des validations rigoureuses.

- Identité Visuelle : Style minimaliste éditorial/magazine.
- Typographie : Hiérarchie très forte, police sans-serif neo-grotesque (Inter), majuscules et tracking large pour les labels.
- Design : Flat design premium, bordures fines (1px ou 2px), pas ou peu d'ombres, coins carrés ou très légèrement arrondis (sauf exceptions spécifiques).
- Palette : Bleu pastel (#A8DADC), orange doux (#FFB347), beige (#F5F5DC), rose corail (#FF5A5F), noir doux (#1A1A1A), blanc cassé (#FDFDFD).
- Principes : Espacement généreux (whitespace), alignements rigoureux, contraste fort entre les titres massifs et les petits labels.
